# Catppuccin Mocha - Unified Color Palette

A warm, dark theme with excellent contrast. Mauve accent preserves the violet feel.

Reference: https://github.com/catppuccin/catppuccin

## Base Colors

| Name     | Hex       | Usage                        |
|----------|-----------|------------------------------|
| crust    | `#11111b` | Deepest background (bars)    |
| base     | `#1e1e2e` | Main background              |
| mantle   | `#181825` | Slightly elevated surfaces   |
| surface0 | `#313244` | Cards, panels, input fields  |
| surface1 | `#45475a` | Hover states, borders        |
| surface2 | `#585b70` | Active states, selections    |

## Overlay Colors

| Name     | Hex       | Usage                        |
|----------|-----------|------------------------------|
| overlay0 | `#6c7086` | Borders, dividers            |
| overlay1 | `#7f849c` | Secondary borders, muted UI  |
| overlay2 | `#9399b2` | Tertiary UI                  |

## Text Colors

| Name     | Hex       | Usage                        |

## Hyprland Border (RGBA)

- Active: `rgba(cba6f7ee) rgba(89b4faee) 45deg` (mauve→blue gradient)
- Inactive: `rgba(313244aa)`

## Shadow

- Color: `rgba(1a1a1aee)`
